# 통계 원본자료 보관 목록

이 문서는 나침반 분석에 사용하는 통계 원본의 실제 파일명·보관 위치·확보 상태를 관리합니다. PC와 GitHub 보관 여부를 구분하며, 권장 파일명과 실제 파일명을 혼동하지 않습니다.

## 보관 위치와 파일명 원칙

- PC 보관 위치: `나침반/data/원자료/PC_원본파일/`
- 아래 파일명은 여러 출처의 파일을 일관되게 관리하기 위한 **권장 로컬 파일명**입니다.
- MDIS가 내려주는 실제 다운로드 파일명은 과거 대화 기록만으로 확인되지 않은 경우가 있으므로, 다운로드 후 아래 권장 파일명으로 바꾸어 보관합니다.
- 원본 파일의 내용은 수정하지 않습니다. 파일명만 정리하고, 압축파일은 가능하면 원본 압축본도 함께 보관합니다.
- 비공개·개인정보 포함 자료 및 재배포 제한 자료는 저장소에 올리지 않습니다.

## 확보 상태를 해석하는 방법

- **실제 파일 확인**: 현재 GitHub 또는 사용자 PC에서 해당 파일 자체를 확인한 자료.
- **원표 다운로드본 보관 대상**: 기준데이터의 출처는 확인되지만, 원본 파일 자체의 보관 여부와 실제 파일명은 확인되지 않은 자료.
- 실제 파일명과 권장 파일명을 별도 표기하며, 확인되지 않은 파일의 존재를 가정하지 않습니다.
