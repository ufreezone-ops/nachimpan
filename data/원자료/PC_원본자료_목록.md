# PC 보관용 통계 원본자료 목록

이 문서는 **사용자 PC의 `나침반/data/원자료/PC_원본파일/`에 내려받아 보관할 원본 파일 목록**입니다.

원본 파일은 용량 및 관리 목적상 GitHub에 올리지 않습니다. 이 목록과 산출 기준만 `dev` 브랜치에서 관리합니다.

## 보관 위치와 파일명 원칙

- PC 보관 위치: `나침반/data/원자료/PC_원본파일/`
- 아래 파일명은 여러 출처의 파일을 일관되게 관리하기 위한 **권장 로컬 파일명**입니다.
- MDIS가 내려주는 실제 다운로드 파일명은 과거 대화 기록만으로 확인되지 않은 경우가 있으므로, 다운로드 후 아래 권장 파일명으로 바꾸어 보관합니다.
- 원본 파일의 내용은 수정하지 않습니다. 파일명만 정리하고, 압축파일은 가능하면 원본 압축본도 함께 보관합니다.
- 비공개·개인정보 포함 자료 및 재배포 제한 자료는 저장소에 올리지 않습니다.

## 확보 상태를 해석하는 방법

- **확보 확인**: 이전 대화에서 사용자가 다운로드하고 분석한 사실이 확인된 자료.
- **원표 다운로드본 보관 대상**: 현재 GitHub 기준데이터와 README에서 출처가 확인되지만, PC에 내려받은 원본 파일의 존재·정확한 파일명까지는 확인되지 않은 자료. 원본을 확보하면 상태를 갱신합니다.
- 이 목록의 권장 파일명은 실제 기관 다운로드 파일명을 확인했다는 뜻이 아닙니다. 특히 RAW-01의 MDIS 실제 다운로드 파일명은 과거 기록에서 확인되지 않았습니다.
