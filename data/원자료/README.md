# 원자료 보존 및 PC 원본자료 목록

이 폴더는 통계기관에서 내려받은 원본 자료의 출처·다운로드 조건·파일명을 기록하고, 재현 가능한 원자료를 관리하는 공간입니다.

## 관리 원칙

- 앱 계산에 직접 사용하는 가공·검증 데이터는 `../기준데이터/`에 둡니다.
- 다운로드한 원본 통계 파일은 사용자 PC의 `나침반/data/원자료/PC_원본파일/`에 보관합니다.
- 원본 파일은 용량 및 관리 목적상 GitHub에 업로드하지 않습니다.
- GitHub에는 원본 파일의 목록, 권장 로컬 파일명, 출처, 다운로드 조건, 변수, 산출 절차만 기록합니다.
- PC의 `PC_원본파일/` 폴더는 저장소 최상위 `.gitignore`에서 제외해 실수로 원본 파일이 커밋되지 않도록 합니다.
- 원자료는 수정·덮어쓰기하지 않습니다. 분석을 위한 변수 선택, 필터링, 가중치 계산 및 단위 변환은 별도 문서 또는 코드로 기록하고 결과물은 `../기준데이터/`에 저장합니다.
- 개인정보·비공개 자료·재배포 제한 자료는 GitHub에 업로드하지 않습니다. 공개·제공 조건을 먼저 확인합니다.

## 원본 파일 목록

PC에 보관할 자료와 권장 파일명은 [PC_원본자료_목록.md](PC_원본자료_목록.md)를 확인하세요.

현재 과거 대화에서 다운로드·분석 사실이 확인된 핵심 원자료는 2024년 MDIS 가계동향조사 연간 지출 마이크로데이터입니다. 그 외 자료는 기준데이터의 출처는 확인되지만, PC에 저장된 원본 파일의 존재와 정확한 다운로드 파일명은 별도 확인이 필요합니다.

## 폴더 구조

```text
나침반/
└── data/
    ├── 기준데이터/              # GitHub 관리: 앱 계산용 가공·검증 자료
    └── 원자료/
        ├── README.md            # GitHub 관리: 보관 원칙
        ├── PC_원본자료_목록.md  # GitHub 관리: PC 원본 파일 목록
        └── PC_원본파일/         # PC 전용: 다운로드 원본, GitHub 업로드 금지
```
