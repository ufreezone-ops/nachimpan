# 원자료 보존

이 폴더는 통계기관에서 내려받은 원본 자료와 재현 가능한 원자료 파일을 보존하는 공간입니다.

## 관리 원칙
- MDIS 마이크로데이터, 원본 엑셀·CSV, 공식 통계표 등 원형을 유지해야 하는 파일을 보관합니다.
- 원자료는 수정·덮어쓰기하지 않습니다. 분석을 위한 변수 선택, 필터링, 가중치 계산 및 단위 변환은 별도 스크립트 또는 문서로 기록하고 결과물은 `../기준데이터/`에 저장합니다.
- 파일명에는 기관, 조사명, 기준연도, 자료 형태를 명시합니다.
- 개인정보·비공개 자료·재배포 제한 자료는 저장소에 업로드하지 않습니다. 공개·제공 조건을 먼저 확인합니다.
- 원자료를 저장하지 못하는 경우에는 원자료 파일 대신 출처 URL, 다운로드 조건, 추출 변수, 산출 절차를 기록한 README를 둡니다.

현재 dev 브랜치에는 확인된 MDIS 원자료 파일이 아직 포함되어 있지 않습니다. 기존 `data/`에 있던 CSV들은 가공된 기준자료로 분류했습니다.
