# 원자료 보존 및 PC 원본자료 목록

이 폴더는 통계기관에서 내려받은 원본 자료의 출처·다운로드 조건·파일명을 기록하고, 재현 가능한 원자료를 관리하는 공간입니다.

## 관리 원칙

- 앱 계산에 직접 사용하는 가공·검증 데이터는 `../기준데이터/`에 둡니다.
- 다운로드한 원본 통계 파일은 원본 그대로 보존합니다. PC와 GitHub 중 어디에 보관하는지는 파일의 크기·이용조건·재현 필요성을 고려해 개별 기록합니다.
- 원본 파일을 GitHub에 올릴 때는 공개·제공 조건과 용량을 확인하고, 앱 계산용 가공자료와 폴더를 구분합니다.
- GitHub에는 원본 파일 자체 또는 원본 파일의 목록·출처·다운로드 조건·변수·산출 절차를 관리합니다.
- PC의 `PC_원본파일/` 폴더는 저장소 최상위 `.gitignore`에서 제외해 실수로 원본 파일이 커밋되지 않도록 합니다.
- 원자료는 수정·덮어쓰기하지 않습니다. 분석을 위한 변수 선택, 필터링, 가중치 계산 및 단위 변환은 별도 문서 또는 코드로 기록하고 결과물은 `../기준데이터/`에 저장합니다.
- 개인정보·비공개 자료·재배포 제한 자료는 GitHub에 업로드하지 않습니다. 공개·제공 조건을 먼저 확인합니다.

## 원본 파일 목록

PC에 보관할 자료와 권장 파일명은 [PC_원본자료_목록.md](PC_원본자료_목록.md)를 확인하세요.

현재 GitHub dev 브랜치에는 2024년 MDIS 가계동향조사 연간 지출 마이크로데이터 원본이 실제 파일로 저장되어 있습니다. 파일명은 `2024_연간자료(지출, 2019~) - 전체가구_1인이상_20261104_13749.csv`이며, 13,478개 관측치와 6개 변수를 포함합니다. 다른 자료는 원본 파일의 실제 보관 여부와 파일명을 별도로 확인해야 합니다.

## 폴더 구조

```text
나침반/
└── data/
    ├── 기준데이터/              # GitHub 관리: 앱 계산용 가공·검증 자료
    └── 원자료/
        ├── README.md            # GitHub 관리: 보관 원칙
        ├── PC_원본자료_목록.md  # GitHub 관리: PC 원본 파일 목록
        ├── 2024_연간자료(...)  # GitHub dev에 보관 중인 MDIS 원본
        └── PC_원본파일/         # PC에 별도 보관하는 원본(존재 여부는 목록에서 확인)
```
