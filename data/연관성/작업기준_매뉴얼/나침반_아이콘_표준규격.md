# 나침반 아이콘 표준규격

- 관리번호: UI-002
- 상태: **시험 중**
- 적용 기준 브랜치: `dev`
- 마지막 조사: 2026-11-21

## 1. 목적과 기본 원칙

나침반은 단순한 장식 아이콘이 아니라, 화면의 맥락에 따라 보고서·자료·연결창으로 이동시키는 탐색 수단이다. 역할과 제목 위계, 실제 DOM 구조가 다르므로 모든 나침반을 같은 버튼 모양이나 클릭 영역으로 강제 통일하지 않는다.

**기본 절차:** 분류 → 구조 파악 → 규격 비교 → 수정 합의 → 적용 → 검증 → 문서화.

기존 나침반 CI와 아이콘 형태를 보존한다. 임의의 새 아이콘으로 대체하거나, DOM 확인 없이 상위 컨테이너에 포괄 CSS를 적용하지 않는다.

## 2. 나침반의 역할 분류

| 유형 | 역할 | 기본 검토 항목 |
|---|---|---|
| 제목 연결버튼 | 제목과 함께 배치되어 해당 항목의 이해에 필요한 자료·보고서로 이동 | 제목 위계, 제목과 아이콘의 DOM 관계, 각각의 클릭 동작, 간격·수직 정렬 |
| 자료 연결 버튼 | 특정 자료·보고서·통계 또는 연결창으로 이동 | 클릭 대상, 자료 ID, 복귀 위치, 탐색 이력 |
| 메뉴·장식형 | 메뉴 정체성이나 화면 안내를 보조 | 장식과 실제 클릭 기능의 구분, 불필요한 클릭 오인 방지 |

## 3. 제목 연결버튼의 위계 구분

제목 연결버튼은 실제 화면의 제목 위계와 컨테이너에 따라 다음과 같이 나눈다.

- 대제목
- 소제목
- 카드 제목
- 입력 항목

제목과 아이콘이 같은 버튼 안에 있는지, 별도 요소인지, 제목 전체와 아이콘 각각이 독립적으로 클릭되는지 실제 DOM으로 확인한다. 같은 시각 규격을 적용하더라도 클릭 영역과 부모 컨테이너 구조는 역할에 맞게 유지한다.

## 4. 대표 적용 사례 — 세대 계승 생애주기 재정곡선

### 4.1 적용 위치와 코드 구조

- 화면: `인생의 사계절` 탭
- 렌더러: `render_official_nta_section()`
- 상위 블록: `6.03.01.01`
- 제목 행 key: `nta-generational-title-row`
- 통합 제목·나침반 버튼 key: `nta_generational_title_open`
- 대표 보고서 source ID: `6051700-00`

제목과 나침반은 첫 번째 사례인 `우리 가정 생애주기 재정곡선`과 동일하게 **하나의 버튼 라벨**로 구성한다. 고급모드에서는 제목 끝에 나침반을 표시하며, 제목과 나침반이 같은 버튼·같은 클릭 영역을 공유한다. 기본모드에서는 기존 표시 조건에 맞춰 제목만 표시한다.

### 4.2 현재 코드에 선언된 제목형 규격

| 항목 | 선언값 |
|---|---:|
| 제목 글자 크기 | 28.8px (실제 라벨 요소에 직접 지정) |
| 제목 글자 굵기 | 700 |
| 제목 최소 높이 | 2.45rem |
| 제목 수직 보정 | translateY(4.2px) |
| 제목 배경·테두리·그림자 | 투명 / 없음 / 없음 |
| 나침반 표시 | 제목 버튼 라벨 끝에 인라인 표시 |
| 클릭 영역 | 제목과 나침반이 하나의 버튼을 공유 |
| 제목 행 정렬 | 수평 컨테이너의 중앙 수직 정렬 |

위 값은 코드의 CSS 선언값이다. 실제 브라우저의 계산값·박스 치수와 같다고 단정하지 않는다. 첫 번째 사례인 `우리 가정 생애주기 재정곡선`의 제목형 버튼과 동일한 글자 크기·굵기·최소 높이·수직 보정값을 기준으로 적용했다.

### 4.3 공통 이동 흐름

제목 문구와 나침반은 하나의 버튼이므로 어느 위치를 눌러도 다음 상태를 함께 설정한다.

1. 대표 보고서 창 열기
2. 보고서 source ID를 `6051700-00`으로 설정
3. 탐색 이력을 해당 보고서에서 시작
4. 최초 진입 탭을 `인생의 사계절`로 기록
5. 복귀 anchor를 `.st-key-nta-generational-title-row`로 기록

대표 보고서 창 하단의 `연결` 버튼은 기존 연결창을 연다. 연결창을 닫으면 최초 진입 탭의 제목 행으로 복귀한다. 보고서 창의 `닫기` 역시 최초 진입 위치가 보존된 경우 그 위치로 돌아간다.

차트 자체의 클릭 브리지는 별도 기능이다. 차트 클릭은 현재처럼 연결창으로 직접 이동하며, 제목·나침반의 대표 보고서 경유 흐름과 혼동하지 않는다.

### 4.4 적용 범위와 예외

- 제목 버튼은 기본모드와 고급모드에서 공통 렌더러를 통해 표시된다.
- 나침반은 기존 조건을 보존하여 고급모드에서 제목 버튼 라벨 끝에 표시한다.
- 다른 제목·나침반에 이 사례의 CSS를 일괄 적용하지 않는다. 각 대상의 제목 위계와 DOM을 먼저 조사한다.
- 제목을 Markdown 제목에서 버튼으로 전환했으므로, 시각적 크기뿐 아니라 제목의 접근성·키보드 탐색도 실제 화면에서 확인한다.

## 5. 두 번째 적용 사례 — 은퇴 후에는?

### 5.1 적용 위치와 코드 구조

- 화면: `우리집 가계부` 탭의 고급모드, 은퇴 후 가정 입력 패널
- 상위 블록: `6.01.05`
- 제목 행 key: `retirement-expense-title-row`
- 통합 제목·나침반 버튼 key: `retirement_expense_title_open`
- 연결 자료 source IDs: `6050400-01`, `6051400-00`, `6051300-00`

기존에는 Markdown 제목과 별도의 `🧭` 버튼이 나란히 배치되어 있었다. 변경 후에는 제목 문구를 단일 버튼 라벨로 사용하고, 나침반은 버튼의 CSS `::after` 가상 요소로 표시한다. 제목과 아이콘은 같은 클릭 영역을 공유한다.

### 5.2 플랫폼 공통 아이콘 규격

- 유니코드 이모지 대신 인라인 SVG 벡터를 CSS 배경 이미지로 사용한다.
- 운영체제별 이모지 글꼴에 의존하지 않으므로 PC와 iPhone에서 동일한 형상·색상으로 렌더링된다.
- 황금색 외곽 링과 방위 바늘, 짙은 녹색 내부를 사용한다.
- 아이콘 크기: 1.85rem × 1.85rem
- 제목 글자 크기: 1.8rem (28.8px), 굵기 700
- 제목과 아이콘 간격: 0.28rem
- 버튼 배경·테두리: 투명 / 없음
- 키보드 포커스: 황금색 외곽선

표지 이미지에서 사용하는 나침반 파일을 직접 잘라 쓴 것은 아니며, 앱 본문에서 플랫폼 간 동일한 표시를 보장하기 위한 고정형 SVG 아이콘이다.

### 5.3 이동 및 복귀 흐름

제목 또는 나침반을 누르면 기존 연결창을 직접 연다. 기존 자료 ID와 탐색 흐름은 유지한다.

1. 연결창 열기: `_retirement_connection_open = True`
2. 자료 목록: `6050400-01`, `6051400-00`, `6051300-00`
3. 최초 진입 탭: `selected_page` 값 보존
4. 복귀 anchor: `.st-key-retirement-expense-title-row button`
5. 기존 탐색기·자료 이력 상태는 기존 코드와 동일하게 초기화

연결창을 닫았을 때 제목 행으로 돌아오는 동작은 기존 anchor를 그대로 사용한다.

## 6. 검증 체크리스트

현재 단계는 **코드 반영 및 정적 재확인**이다. 아래 화면 검증이 끝나기 전에는 확정으로 상태를 바꾸지 않는다.

- [ ] PC에서 제목 클릭 시 대표 보고서 창이 열린다.
- [ ] PC에서 나침반 클릭 시 같은 대표 보고서 창이 열린다.
- [ ] 보고서 하단 `연결` 버튼으로 기존 연결창이 열린다.
- [ ] 연결창의 이전·다음 탐색과 보고서 이력이 정상 작동한다.
- [ ] 연결창을 닫으면 최초 제목 행으로 복귀한다.
- [ ] 보고서 창에서 직접 닫아도 최초 위치로 복귀한다.
- [ ] iPhone에서 위 항목을 동일하게 확인한다.
- [ ] 제목·나침반의 크기, 간격, 기준선, 클릭 영역을 실제 DOM과 대조한다.
- [ ] 키보드 포커스와 제목 의미가 사용성에 문제 없는지 확인한다.
