- 관리번호: UI-001
- 상태: **시험 중**
- 적용 기준 브랜치: `dev`
- 마지막 조사: 2026-11-21

## 1. 목적

나침반 앱에서 반복 사용하는 버튼의 외형을 일관되게 관리한다. 현재 기준 디자인은 지하철 2호선 안내판에서 착안한 녹색 테두리의 흰색 캡슐형 버튼이다.

이 문서는 버튼의 공통 시각 규격과 예외 치수를 구분한다. 모든 버튼의 전체 폭·높이·클릭 영역까지 무조건 같게 만드는 문서는 아니다.

## 3. 현재 공통 CSS 적용 대상으로 확인된 버튼

| 화면/역할 | Streamlit key 또는 선택자 | 폭 규칙 |
|---|---|---|
| 자료보기 창의 연결 버튼 | `retirement-report-connection-cta` | 120px |
| 연결창 하단 닫기 버튼 | `retirement-connection-close-cta` 내부 `retirement_connection_end` | 별도 규칙에서 65px |

공통 스타일은 세 대상에 같은 테두리·배경·글자·높이·패딩 값을 적용하도록 작성되어 있다. 버튼 폭은 역할과 문구 길이에 따라 별도 규칙을 허용한다.

## 4. 중요한 구분: CSS 선언값과 실제 렌더링 치수

공통 CSS 변수에 같은 값이 선언되어 있다는 사실만으로 실제 브라우저에서 버튼의 바깥 크기·내부 텍스트 영역·클릭 영역까지 같다고 판단하지 않는다.

2026-11-20 사용자 DOM 확인 메모:

- 통계 창의 **‘연결창으로’**: border 상하좌우 6px, padding 상하 4.8px / 좌우 1.6px, 측정 영역 88.813 × 16.805
- 연결창의 **‘닫기’**: border 상하좌우 6px, padding 상하좌우 5.6px, 측정 폭 41px

위 값은 사용자가 개발자 도구에서 확인한 측정 메모이며, 측정 대상이 버튼 외곽인지 내부 요소인지 및 브라우저의 실제 박스 모델을 다시 대조해야 한다. 공통 CSS의 선언값과 차이가 있으므로 현 단계에서는 버튼 치수 통일이 완료됐다고 기록하지 않는다.

**검증 원칙:** 개발자 도구에서 바깥 `button`, 내부 텍스트 래퍼, 텍스트 요소를 구분해 확인한다. PC와 iPhone에서 각각 실제 표시를 확인하고, CSS 선언값·계산된 값·측정된 박스 크기를 별도로 기록한다.

## 5. 적용 및 수정 원칙

1. 먼저 대상 버튼의 실제 Streamlit key와 DOM 구조를 확인한다.
2. 공통 외형은 공통 CSS 변수를 우선 사용한다.
3. 버튼 폭·배치·클릭 영역은 역할별 예외 규칙으로 관리한다.
4. 예외 규칙은 공통 규격을 무력화하지 않도록 적용 범위를 해당 key로 제한한다.
5. 중복 선택자와 뒤늦게 추가된 덮어쓰기 규칙을 조사한 뒤 수정한다.
6. 기존 버튼의 기능, 콜백, 화면 전환은 외형 변경과 분리해 보존한다.
7. 실제 PC·모바일 검증 전에는 상태를 **확정**으로 변경하지 않는다.

## 7. 적용 사례 — 부동산 적용기준 창 하단 버튼

- 적용 위치: `🏠 부동산 적용 기준` 대화상자 하단
- 상위 컨테이너 key: `housing-price-dialog-actions`
- 연결 버튼 key: `housing_price_open_connection`
- 닫기 버튼 key: `close_housing_price_stats_dialog`
- 방법 안내 화면의 닫기 버튼 key: `close_housing_price_method_dialog`

### 7.1 배치 및 외형

- `연결`과 `닫기`를 같은 행에 나란히 배치한다.
- 두 버튼은 2호선형 공통 CSS 변수와 공통 버튼 규격을 사용한다.
- PC에서는 각 버튼 폭 120px, 480px 이하에서는 각 104px로 제한한다.
- 공통 높이 2.4rem, 테두리 6px, 캡슐형 모서리, 흰색 배경, 녹색 테두리, 검정 글자, 14.4px / 850 굵기를 적용한다.
- Hover 배경은 `#E8F5EC`를 사용한다.
- 버튼의 기능·콜백은 외형 규칙과 분리해 보존한다.

### 7.2 종료 방식

이 대화상자는 우상단 기본 `X`를 숨기고 하단의 명시적 `닫기` 버튼으로 종료한다. 정상 종료 시 `_housing_price_dialog_open = False`로 설정하고 `_housing_dialog_view`를 `summary`로 초기화한다. 방법 안내 화면에서도 별도의 하단 닫기 버튼을 제공한다.

### 7.3 연결 기능 보존

`연결` 버튼은 기존 동작을 유지한다. 부동산 적용기준 창을 닫고, 은퇴 탐색기·연결창 상태를 설정하며, 최초 진입 탭과 `.st-key-housing-price-title-row button` 복귀 위치 및 source ID `6051500-00`을 보존한다.
