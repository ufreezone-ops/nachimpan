# KB 연간 주택매매가격지수 — 17개 시도

## 목적
나침반의 주택 구입 이벤트에서 지역과 주택유형에 따른 **장기 가격변동**을 반영하기 위한 연간 지수 자료다.

앱에서 사용하는 지역 선택 기준에 맞춰 17개 시도만 추출했고, 주택유형은 `아파트`와 `주택종합` 두 가지로 제한했다. 월간 원자료 전체는 사용자 PC에 보관하며, GitHub `dev`에는 이 연간 CSV와 README만 둔다.

## 자료 구성
- 파일: `KB_연간_주택가격지수_17개시도_1986-2026.csv`
- 기간: 1986~2026년
- 지역: 17개 시도
- 주택유형: 아파트, 주택종합
- 관측치: 41개 연도 × 17개 지역 × 2개 유형 = 1,394개 지수 셀
- CSV 구조: 연도별 1행, 지역·주택유형별 34개 지수 열
- 지수 기준: **2026년 1월 = 100.0**
- 연간값: 해당 연도에 관측된 월별 지수의 산술평균
- 2026년: 1~10월 평균(10개월)이며 완전한 연간 평균이 아님

## 지역 구성
서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종, 경기, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주.

지역명은 나침반의 기존 입력값과 동일하게 `서울`, `부산`, `대구`, `인천`, `광주`, `대전`, `울산`, `세종`, `경기`, `강원`, `충북`, `충남`, `전북`, `전남`, `경북`, `경남`, `제주`로 정리했다.

광주와 전남은 원본 시트에서 각각 `(구)광주광역시`, `(구)전라남도`로 표시된 기존 지역 시계열을 사용했다. 원본에 별도 표시된 `전남광주 통합특별시` 집계는 나침반의 기존 17개 시도 구분과 맞지 않아 포함하지 않았다.

## 주택유형 정의
- `아파트`: 원본 시트 `2.매매APT`
- `주택종합`: 원본 시트 `1.매매종합`. 아파트·단독주택·연립주택 등 주택유형 전체를 포괄하는 종합지수다.
- `주택종합`은 단독주택만을 의미하는 `일반주택`과 다르다. 나침반에서 두 선택지를 표시할 때도 `아파트 / 주택종합`이라는 명칭을 권장한다.

## CSV 열 이름
각 지역마다 아래 두 열이 있다.
- `아파트_지역명`
- `주택종합_지역명`

예: `아파트_부산`, `주택종합_부산`, `아파트_서울`, `주택종합_서울`.

`year`는 연도이며, 각 지수 열은 해당 연도의 관측 월별 지수 산술평균이다. 관측값이 없는 지역·연도는 빈칸으로 둔다. 결측 월을 보간하거나 임의로 채우지 않았다.

## 지역별 시계열 시작 시점
- 서울·부산·대구·인천·광주·대전·울산: 1986년부터
- 경기·강원·충북·충남·전북·전남·경북·경남·제주: 2003년부터
- 세종: 2013년부터

지역별 과거 자료의 시작 시점이 서로 다르므로 초기 연도에는 일부 지역 값이 비어 있다. 2026년은 모든 지역에서 1~10월 자료를 사용했다.

## 통시성 보정 적용식
기준연도 가격을 목표연도의 가격 수준으로 환산할 때 같은 지역·주택유형의 연간 평균 지수를 사용한다.

`목표연도 환산가격 = 기준연도 가격 × (목표연도 연간 평균지수 ÷ 기준연도 연간 평균지수)`

예를 들어 2024년 기준 주택 구입비용을 2025년 가격 수준으로 환산할 때는 해당 지역·주택유형의 `2025년 연간 평균지수 ÷ 2024년 연간 평균지수`를 곱한다.

이 지수는 지역 간 절대 주택가격 수준을 비교하는 자료가 아니라, **같은 지역·같은 주택유형 안에서 시간에 따른 가격변화를 환산**하는 자료다. 실제 가격 수준이나 주택 구입 자기자금은 별도의 가격 통계와 구분한다.

## 미래 연도 처리 원칙
실측 자료는 2026년 10월까지다. 2027년 이후 지수는 관측값이 아니므로 이 파일에 임의로 추가하지 않는다. 미래 주택 구입 이벤트에 적용할 때는 별도의 미래 가격상승 시나리오를 정하거나, 최신 관측 지수를 유지하는 방식 중 무엇을 사용할지 명시해야 한다. 최신 지수를 유지하는 것은 미래 가격이 정체된다는 예측이 아니라 계산상 가정이다.

## 가공 및 관리 원칙
1. 원본 엑셀은 사용자 PC의 별도 통계 원본 폴더에 보관한다.
2. GitHub `dev`에는 이 연간 CSV와 README만 둔다. 월간 원본 엑셀과 월간 전체 CSV는 앱에 포함하지 않는다.
3. `main` 반영은 `dev`에서 데이터와 앱 동작을 확인한 뒤 별도 승인 후 진행한다.
4. 원본 파일이 갱신되면 동일한 지역·유형 매핑과 연간 평균 산출 규칙으로 다시 생성한다.
5. 이전에 별도로 확보한 `2022.01=100.0` 기준 표와 이 파일의 `2026.01=100.0` 지수값을 섞지 않는다. 이 앱 데이터는 이 엑셀 파일 기준으로 일관되게 사용한다.

## 유의사항
- KB 지수는 조사·추정에 기반한 가격변동 지수이며 실제 개별 주택의 거래가격이나 특정 가구의 구입가격이 아니다.
- 연간 평균은 12월 말 지수와 다르다. 이 파일은 소비자물가지수·임금지수와 연 단위로 비교하기 쉽도록 월별 지수의 연간 평균을 사용한다.
- 지역 경계·조사범위·통계작성 방법의 변경 가능성이 있으므로 장기 시계열 해석 시 원자료의 조사개요를 함께 확인한다.
- 2026년 값은 10개월만 반영한 부분연도 값이므로 1986~2025년의 완전한 연평균과 직접 비교할 때 주의한다.
