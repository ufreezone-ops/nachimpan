# 국토교통부 2024년 주거실태조사 — 생애최초 주택 구입자금 구성

## 자료 개요
- 작성기관: 국토교통부
- 조사명: 2024년 주거실태조사(일반가구)
- 원자료 제공: 국가통계 마이크로데이터 통합서비스(MDIS)
- 이번 추출본: 61,341가구 × 41개 변수
- 분석 결과물: 본 CSV는 개인·가구 단위 원자료가 아니라, 가중치를 적용해 집계한 파생 통계표
- 원자료 ZIP은 공개 저장소에 올리지 않고 별도 보관한다.

## 기존 생애최초 주택 마련 연령 파일과의 관계
기존 파일 `국토교통부_2024_주거실태조사_생애최초주택마련연령.csv`은 생애최초 주택 마련 연령의 분포와 중앙값을 보여준다.
이번 파일은 문13의 자금 출처를 이용해 자기자금·금융기관 융자·기타 차입·부모/친지 지원의 구성비를 보여준다.
두 파일은 같은 2024년 조사에서 출발하지만 분석 목적과 집계 단위가 다르므로 삭제하거나 하나로 합치지 않고 나란히 보존한다.

## 원자료 선택 변수
- 시도
- 문1 가구주 또는 배우자 여부
- 문3 현재 주택 거주 시작 연도
- 문4 현재 주택 유형
- 문8 가구주가 된 이후 자가주택 마련 경험
- 문8-1 생애최초 주택 마련 연도
- 문8-2 현재 주택이 생애최초 주택인지
- 문8-3 생애최초 주택 마련까지 걸린 기간(년·개월·총개월)
- 문8-4 생애최초 주택 면적(평·㎡)
- 문12 현재 주택가격 및 매입/증여/상속 당시 주택가격
- 문13 자기자금, 금융기관 융자, 금융기관 외 차입, 부모·친지 무상지원
- 가구 구성원 1~11의 가구주와 관계 및 출생연도
- 최종가중치

## 집계 및 산출 기준
- 자금 구성 분석은 문13 네 항목이 모두 유효하고 0 이상이며, 네 항목 합계가 0보다 큰 가구를 대상으로 한다.
- 최종가중치가 양수인 가구만 포함한다.
- 각 자금 출처의 비율은 가구별 비율의 단순평균이 아니다. 각 출처 금액에 최종가중치를 곱해 합산한 뒤, 네 출처 가중금액 합계에서 차지하는 비중으로 계산한다.
- 전체 유효 자금 표본: 29,992가구.
- 현재 주택이 생애최초 주택인 유효 자금 표본(문8-2=1): 16,159가구.
- 그중 현재 주택 유형이 아파트인 표본(문4=4): 10,607가구.
- 취득 연령은 문8-1 생애최초 주택 마련 연도에서 가구 구성원 No.1(가구주)의 출생연도를 뺀 연도 차이로 계산한다. 실제 만 나이와 생일 차이로 최대 1세 오차가 있을 수 있다.
- 연령대별 자금 구성은 현재 주택이 생애최초 주택이며, 현재 주택 유형이 아파트인 가구를 기준으로 한다.
- 지역별 구성도 동일한 생애최초 아파트 표본을 기준으로 한다.
- 주택유형별 표는 현재 주택이 생애최초 주택인 가구를 유형별로 구분한다.

- 생애최초 아파트 전체: 자기자금 70.05%, 금융기관 융자 24.50%, 금융기관 외 차입 0.29%, 부모·친지 무상지원 5.17%.
- 생애최초 아파트 30~34세 취득 집단: 자기자금 59.91%, 금융기관 융자 31.13%, 금융기관 외 차입 0.54%, 부모·친지 무상지원 8.43%.
- 생애최초 아파트 35~39세 취득 집단: 자기자금 65.29%, 금융기관 융자 28.54%, 금융기관 외 차입 0.38%, 부모·친지 무상지원 5.79%.
- 부산 생애최초 아파트 전체: 자기자금 65.76%, 금융기관 융자 30.18%, 금융기관 외 차입 0.52%, 부모·친지 무상지원 3.54%.
- 부산 생애최초 아파트 30~39세 취득 집단: 비가중 표본 307가구, 자기자금 58.92%, 금융기관 융자 35.45%, 금융기관 외 차입 0.71%, 부모·친지 무상지원 4.91%.

## CSV 열 설명
- `분석차원`: 전체, 생애최초, 취득연령_아파트, 지역_아파트, 주택유형_생애최초 등 집계 구분
- `분석집단`: 해당 차원 안의 연령대·지역·주택유형

- `가중가구수`: 최종가중치 합계
- `자기자금_pct`: 네 가지 구입자금 가중금액 합계 중 자기자금 비중(%)
- `금융기관융자_pct`: 금융기관 융자 비중(%)
- `금융기관외차입_pct`: 금융기관 외 차입 비중(%)
- `부모친지지원_pct`: 부모·친지 무상지원 비중(%)
- `분석메모`: 집계 필터 및 해석 메모

## 해석상의 유의사항
1. 문13은 현재 거주 주택의 구입자금 출처를 묻는다. 따라서 현재 주택이 생애최초 주택인 가구(문8-2=1)를 별도로 제한한 경우에만 생애최초 주택 자금 구성으로 해석한다.
2. 금융기관 융자액은 금융기관에서 빌린 금액이며, 모두 주택담보대출이라고 확인된 값이 아니다. 이 비율을 규제상 LTV로 부르거나 그대로 대체해서는 안 된다.
3. 자금 구성비는 주택가격 대비 비율이 아니라, 문13 네 가지 자금 출처 합계 대비 비율이다. 네 항목의 합계가 문12의 주택가격과 반드시 일치한다고 가정하지 않는다.
4. 취득 연령은 연도 차이로 계산한 추정 연령이며, 실제 만 나이와 다를 수 있다.
5. 표본 수가 적은 연령·주택유형 집단(특히 n<100)은 기본값 산정에 사용하지 않고 참고치로만 본다.
6. 2024년 횡단면 조사이며 동일 가구를 추적한 패널자료가 아니다. 과거 취득 경험을 현재 시점에서 회고한 응답을 포함한다.
7. 이 CSV는 통계 탭 설명과 나침반의 통계적 기본값 검토를 위한 집계 결과다. 개인 단위 원자료를 재배포하지 않는다.
