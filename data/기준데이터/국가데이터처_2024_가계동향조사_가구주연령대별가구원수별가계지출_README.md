# 국가데이터처 2024년 가계동향조사 — 가구주 연령대·가구원 수별 가계지출

## 출처
- 작성기관: 통계청(현 국가데이터처)
- 조사명: 가계동향조사(2019~2024년 구분류)
- 자료: 2024년 연간자료(지출, 2019~) - 전체가구 1인 이상(제공)
- 제공기관: 국가통계 마이크로데이터 통합서비스(MDIS)
- 원자료: 이용자가 MDIS에서 내려받은 공공용 마이크로데이터
- 원자료 관측치: 13,478개
- 분석 파일: `국가데이터처_2024_가계동향조사_가구주연령대별가구원수별가계지출.csv`

## 가공 내용
원자료 관측치를 가구주 연령대(5세 단위)와 가구원 수로 교차 분류했다.
- 연령대: 17~19세, 20~24세부터 75~79세까지 5세 단위, 80세 이상
- 가구원 수: 1인, 2인, 3인, 4인, 5인 이상
- 5인 이상은 원자료의 5~8인 가구를 합산
- 각 셀은 원자료 가중값을 적용한 가중평균
- 금액은 원 단위를 만원으로 환산해 소수 둘째 자리까지 표시
- 표본수는 비가중 관측치 수

## 변수
- `가구주_연령대`: 가구주 연령 구간
- `가구원수`: 가구원 수 구분
- `표본수`: 해당 구간의 원자료 관측치 수
- `월평균_가계지출_만원`: 가계지출금액의 가중평균
- `월평균_소비지출_만원`: 소비지출금액의 가중평균
- `월평균_비소비지출_만원`: 비소비지출금액의 가중평균
- `비고`: 표본수 30 미만은 '표본 적음(30 미만)'으로 표시

## 해석 시 유의사항
1. 이 파일은 원자료가 아닌 연령대·가구원 수별 파생 통계표다. 원자료 마이크로데이터는 저장소에 포함하지 않았다.
2. 표본수가 적은 셀은 평균의 변동 가능성이 크다. 특히 25~29세 3인·4인 가구의 표본수는 각각 25개·4개다.
3. 조사상 가계지출과 나침반 입력 지출 항목이 완전히 일치한다고 단정할 수 없다. 대출 원금 상환 등 자산·부채 거래 성격의 항목은 별도 정의 확인이 필요하다.
4. 해당 연령대 가구의 관측 평균이며 특정 개인의 과거 실제 지출을 직접 나타내지 않는다.
5. 가중값을 적용해 재산출한 값으로 공식 공표 통계표와 집계 정의·반올림 방식이 다를 수 있다.

## 재현 방법
가중평균 = Σ(금액 × 가중값) / Σ(가중값)

원자료 변수명: `가구원수`, `가구주_연령`, `가중값`, `가계지출금액`, `가계지출_소비지출금액`, `가계지출_비소비지출금액`.
