# 나침반 자료 간 연관성 — 1차 시범 데이터

이 문서는 초기 1차 시범 데이터의 보관·해석 기록입니다. 현재 앱에서 실제 추천에 사용하는 연결 정보의 기준 파일은 `data/연관성/보고서_쌍별연관성_내용평가_v1.json`이며, 이 1차 시범 파일은 현행 연결 점수의 원천이 아닙니다.

## 파일
- `자료연관성_연결행렬_1차.csv`: 37×37 연관성 점수 행렬. 행과 열은 자료 ID입니다.
- `자료연관성_자료목록_1차.csv`: 자료 ID와 이름의 대응표.

## 범위
- 대상: 보고서 23개 + 데이터 파일 14개 = 37개
- 고유 쌍: 37×36÷2 = 666개
- 점수: 기존 1차 자료 설명 및 의미 태그를 구조화해 계산한 시범 상대점수

## 반드시 유의할 점
이 결과는 원문 전체에 대한 정밀한 문맥 임베딩 분석 결과가 아닙니다. 원문·표·CSV 변수 설명을 전부 대조하기 전의 탐색용 초안이며, 점수는 확률이나 정확도가 아닙니다. 실제 추천에 사용하기 전 표본 검토와 점수 보정이 필요합니다.

또한 D13 CSV와 D14 XLSX는 동일한 국민이전계정 자료의 파일 형식 차이일 가능성이 높으므로, 독립적인 지식 노드로 중복 취급하지 않도록 후속 검증이 필요합니다.
