# 국가데이터처 2024년 가계동향조사 — 가구주 연령대·가구원 수별 가계지출 가중중위값

## 출처와 원자료
- 통계 작성기관: 국가데이터처(당시 통계청)
- 조사명: 가계동향조사(2019~2024년 구분류)
- 자료: 2024년 연간자료(지출, 2019~) - 전체가구 1인 이상
- 제공 서비스: 국가통계 마이크로데이터 통합서비스(MDIS)
- 제공 자료: 제공(공공용) 마이크로데이터
- 원자료 파일: `data/원자료/2024_연간자료(지출, 2019~) - 전체가구_1인이상_20261104_13749.csv`
- 원자료 관측치: 13,478가구(헤더 포함 13,479행)
- 원자료 GitHub 경로: `dev/data/원자료/`

국가데이터처는 조사를 작성·공표하는 통계 작성기관이고, MDIS는 마이크로데이터를 제공하는 서비스다. 두 명칭은 같은 기관을 뜻하지 않는다.

## 산출 대상 및 분류
- 가구주 연령대: 17~19세, 20~24세부터 75~79세까지 5세 단위, 80세 이상
- 가구원 수: 1인, 2인, 3인, 4인, 5인 이상(원자료의 5인 이상을 합산)
- 셀별 표본수: 비가중 가구 관측치 수
- 성별 구분: 원자료에 가구주 성별 변수가 포함되어 있지 않아 산출하지 않음.

## 가중중위값 산출 방법
각 연령대·가구원 수 셀 안에서 해당 지출 변수를 오름차순 정렬한 뒤, 가중값의 누적합이 해당 셀 전체 가중값 합계의 50% 이상이 되는 최초 관측치의 지출액을 가중중위값으로 산출했다.

- 가중치 변수: `가중값`
- 전체 가계지출: `가계지출금액`
- 소비지출: `가계지출_소비지출금액`
- 비소비지출: `가계지출_비소비지출금액`
- 금액 단위: 원에서 만원으로 환산
- 소수점: 만원 단위 소수 둘째 자리까지 표시
- 표본수 30 미만 셀: `표본 적음(30 미만)`으로 표시

소비지출·비소비지출 중위값은 각각 별도로 계산했다. 따라서 두 항목의 중위값을 더한 값이 가계지출 전체의 중위값과 일치해야 하는 것은 아니다. 중위값은 평균과 달리 합산에 대해 선형적이지 않다.

## 기존 평균자료와의 관계
기존 파일 `국가데이터처_2024_가계동향조사_가구주연령대별가구원수별가계지출.csv`는 동일 원자료에서 산출한 가중평균 자료다. 본 파일은 같은 분류체계에서 산출한 가중중위값 자료이며, 기존 평균 파일을 덮어쓰지 않는다.

## 해석상 유의사항
1. 이 자료는 특정 개인의 실제 지출이 아니라 2024년 해당 연령대·가구원 수 가구의 분포상 중위값이다.
2. 가중중위값은 가중치가 반영된 대표값이며, 단순 표본 중앙값과 다르다.
3. 표본수 30 미만 셀은 값의 변동 가능성이 크므로 대표사례 기준으로 사용하는 데 주의한다.
4. 가구주 연령과 가구원 수로 구분했으며 성별 효과는 반영하지 않았다.
5. 가계지출 항목의 조사상 정의와 나침반의 생활비 입력 범위가 완전히 일치하는지는 별도 검토가 필요하다.
6. 이 기준값은 2024년 가격 기준의 월 지출 통계다. 다른 연도와 비교할 때는 물가 환산 기준을 일관되게 적용해야 한다.
