# 국가데이터처 2024년 연령별 임금근로일자리 평균 보수

## 데이터
- 파일: `국가데이터처_2024_연령별_임금근로일자리_평균보수.csv`
- 기준: 2024년 12월 임금근로일자리에서 하루 이상 일한 근로자의 월평균 보수
- 단위: 만 원 / 월 / 세전
- 연령별 구분: 20대, 30대, 40대, 50대, 60대, 70세 이상
- 성별 구분: 전체, 남성, 여성

## 해석 및 사용상 주의
1. 이 값은 임금근로일자리에서 일한 사람의 평균 보수다. 취업하지 않은 사람의 소득은 0으로 포함한 인구 전체 평균이 아니다.
2. 세전 월 보수이며, 사업소득자·특수형태근로종사자 등 일부는 작성 대상에서 제외된다.
3. 그래프에서는 연령대별 월평균 보수에 12를 곱해 연환산 참고값으로 표시한다. 이는 해당 연령대의 실제 연간 총소득을 뜻하지 않는다.
4. 대표연령은 그래프 배치를 위한 표시 좌표다. 특히 '70세 이상'의 75세는 해당 연령집단의 실제 평균연령이나 취업 종료연령을 뜻하지 않는다.
5. 이 통계만으로 73세까지 일하는 비율이나 평균 은퇴연령을 추정할 수 없다. 고용률·경제활동참가율 등과 구분해서 해석해야 한다.

## 앱 적용 원칙
- 개인·가구의 예상소득 곡선과 분리된 통계 비교선으로 사용한다.
- 본인 성별에 맞는 평균 보수 계열을 선택한다.
- 개인별 은퇴 희망 연령과 무관하게 통계 비교선은 표시한다.
- 현재 자료의 최고 연령 구간은 '70세 이상'이므로, 그래프의 마지막 점은 70세 이상 집단의 대표값 표시일 뿐 정확한 노동소득 종료연령이 아니다.
