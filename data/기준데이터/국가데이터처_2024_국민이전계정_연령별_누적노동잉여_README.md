# 2024년 국민이전계정 연령별 누적 노동잉여 기준데이터

## 출처
- 기관: 국가데이터처
- 통계: 2024년 국민이전계정(National Transfer Accounts, NTA)
- 원자료 CSV: `data/원자료/생애주기적자계정_1인규모__20261110084848.csv`
- 원자료 XLSX: `data/원자료/생애주기적자계정_1인규모__20261110082529.xlsx`
- 기준연도: 2024년
- 단위: 1인당 연간 천원
- 연령: 0세~84세, 85세 이상(집단 구간)

## 가공 방법
원자료의 연령별 1인당 소비와 노동소득을 사용합니다.

- 연간 노동잉여 = 노동소득 - 소비
- 생애주기적자 = 소비 - 노동소득
- 0세 기준 누적 노동잉여 = 0세부터 해당 연령까지 연간 노동잉여의 합
- 20세 기준 누적 노동잉여 = 20세부터 해당 연령까지 연간 노동잉여의 합. 0~19세는 빈칸으로 둡니다.

원자료에서 노동소득이 '-'로 표시된 연령은 노동소득 0으로 처리했습니다. 원자료의 생애주기적자와 소비-노동소득의 차이가 일치하는지 검산했습니다. 원자료 값의 소수점 여섯 자리까지 보존했습니다.

## 해석상 유의
이 누적값은 실제 개인의 금융자산 잔액이나 순자산이 아닙니다. 연령별 1인당 평균 노동소득과 소비의 차이를 가상의 생애 경로로 누적한 값입니다. 공적·사적 이전, 자산소득, 자산의 취득·처분, 투자수익, 주택자산 등은 포함하지 않습니다. 따라서 누적값이 양수라고 해서 해당 연령의 개인이 그 금액을 실제 자산으로 보유한다는 뜻은 아닙니다.

85세 이상은 단일 연령이 아니라 집단 구간이므로, 그래프의 마지막 점은 85세 이상 구간을 뜻합니다.
