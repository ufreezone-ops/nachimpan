# 기준데이터

이 폴더에는 나침반 앱이 직접 읽거나 통계 기준선·이벤트 계산에 사용하는 정제·가공 데이터를 보관합니다.

## 관리 원칙
- 앱 계산에 사용하는 파일은 이 폴더에 둡니다.
- 원자료를 그대로 복사한 파일이 아니라, 출처 통계에서 추출·정리·가공한 데이터와 그 산출 근거(README)를 보관합니다.
- 각 데이터 파일에는 조사연도, 통계 단위, 모집단·대상, 가중치 적용 여부, 평균/중위 구분, 변수 정의와 산출 방법을 기록합니다.
- 앱 코드에서는 이 폴더의 파일만 기준 데이터로 직접 참조합니다.
- 평균과 중위값은 통계량의 의미를 구분해 관리합니다. 중위값 기준선을 사용하는 경우 평균 자료를 계산에 혼용하지 않습니다.

## 현재 자료
이 폴더의 개별 CSV와 README를 확인하세요. 기존 지출 CSV는 가중평균 자료이며, MDIS 마이크로데이터에서 가중중위값을 산출한 뒤 새 기준자료로 교체·추가할 예정입니다.
