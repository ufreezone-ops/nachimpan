# 나침반 아이콘 자산

- `compass_pixabay_128.webp`: Pixabay 원본 나침반을 원형으로 크롭하고 바깥 사각 배경을 투명 처리한 128×128 WebP 아이콘.
- 원본 해상도: 1280×1275 PNG.
- 앱 표시 크기: 약 28~32 CSS px 기준. 128px 소스는 약 4배 고해상도 표시용.
- 원본의 N/E/S/W 표기, 눈금, 빨강·파랑 바늘은 수정하지 않음.
- 이미지 자체의 둥근 원형 페이스는 유지하고, 원 바깥쪽만 투명 처리함.
- WebP 품질: 90.

출처:
- Pixabay 이미지 CDN 원본: https://cdn.pixabay.com/photo/2013/07/12/17/38/compass-152124_1280.png
- Pixabay 라이선스: https://pixabay.com/service/license-summary/

참고: 저장소에 추가한 파일은 앱 코드에서 아직 사용하지 않음. 기능성 나침반에 적용할 때는 DOM/버튼 구조를 확인하고 별도 변경으로 진행.
